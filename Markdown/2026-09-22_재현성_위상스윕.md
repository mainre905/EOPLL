## 3. 재현성 — 독립 히스토그램 4개 (`python/tdc_repeatability.py`)

키 1 의 cal 히스토그램 1개 + 키 3 을 세 번 눌러 받은 val 히스토그램 3개. 전부 200만발,
창 2~321, 다이 46.65~46.99 °C.

### 3-1. 결과

| 항목 | 값 |
|---|---|
| 칸 폭 런간 sd | rms **0.247 ps**, 최대 0.768 ps (탭 160) |
| **교정표 런간 sd** | rms **1.398 ps**, 최대 **2.663 ps** (탭 205) |
| 교정표 sd 히트 가중 rms | **1.394 ps** |
| 산탄잡음만이라면 | 1.951 ± 0.457 ps → **관측/기대 = 0.72 배** |

**"교정을 다시 하면 타임스탬프가 평균 1.4 ps 달라진다"** 가 이 숫자의 뜻이다.
합격 기준(≤ 2 ps)을 넘지 않는다.

### 3-2. 산탄잡음보다 작다 — 왜인가

관측이 푸아송 기대치의 0.72 배다. 어제 단독 데이터에서도 0.65 배였다.
**링오실레이터 히트가 독립 무작위가 아니라 규칙적으로 탭을 훑기 때문**이다 (층화 추출이라
누적합의 분산이 무작위 표집보다 작다). 즉 **푸아송 잡음 바닥 식은 이 자극에 대해 보수적**이다.
바꿔 말하면, 히트 수를 늘려도 기대만큼 좋아지지 않을 수 있다.

### 3-3. 온도 상관 — 유의하지 않다

| 런 | 다이 [°C] | 표 평균편차 [ps] |
|---|---|---|
| 1 (cal) | 46.84 | −0.485 |
| 2 | 46.79 | +0.850 |
| 3 | 46.99 | −1.259 |
| 4 | 46.65 | +0.894 |

`r = −0.899`, 회귀 기울기 −6.78 ps/°C. 스크립트는 "온도 의존 있음"으로 찍지만 **믿으면 안 된다** :

- 점이 4개뿐이라 자유도가 2 다. `t = −2.91` 인데 95 % 유의하려면 **|t| > 4.30** 이어야 한다.
- 온도 범위가 **0.34 °C** 뿐이다. 이 폭에서 기울기를 읽는 것 자체가 무리다.

**판정 보류.** 온도 의존은 40 / 60 / 80 °C 처럼 **일부러 온도를 벌려서** 재야 한다
(09-21 보고서 §8-4). 그 실험 전에는 −6.78 ps/°C 를 인용하지 말 것.

### 3-4. 키 3 세 번의 INL/DNL (참고)

| 런 | DNL 후 [LSB] | INL 후 최대 | INL 후 가중 rms |
|---|---|---|---|
| 1 | −0.074 … +0.077 (rms 0.023) | 3.65 ps (탭 249) | 1.78 ps |
| 2 | −0.070 … +0.118 (rms 0.021) | 3.75 ps (탭 38) | 1.42 ps |
| 3 | −0.070 … +0.083 (rms 0.022) | 3.64 ps (탭 258) | 1.63 ps |

**가중 rms 가 1.42~1.78 ps 로 흩어진다** (어제 통합 1.29, 단독 1.56). 이 흩어짐 자체가
§3-1 의 재현성 1.39 ps 와 같은 크기다 — 한 번 재서 나온 "교정 후 INL" 을 소수 둘째 자리까지
비교하는 것은 의미가 없다는 뜻이다.

## 4. 왜 13점으로 늘렸나

5점 적합은 자유도가 3 뿐이다. 같은 보드에서 +228 ppm(09-21 단독), +480 ppm(09-16, 70점),
+789 ppm(09-21 통합) 이 나왔고 어느 것이 참인지 가릴 수 없었다.
위상 목록을 `{20, 40, …, 260}` 13점으로 바꿨다 (`vitis/tdc_app.c:193`, 커밋 `dce8470`).
비트스트림은 그대로 두고 앱만 재빌드했다.

Orin 에서 같은 점으로 다시 적합했고 기울기 오차 +812 ppm, 잔차 10.29 ps 로 **보드와 일치**한다.

### 5-2. ★ 기울기는 여전히 "측정 불가" 다

잔차에서 기울기의 표준오차를 구하면 :

```
SE(기울기) = 잔차rms / sqrt(Σ(x - x̄)²)
           = 10.29 ps / sqrt(72800 step²) = 0.0382 ps/step
           = 0.0382 / 17.8571 = ±2137 ppm  (1σ)
```

측정값 +812 ppm 은 **0 에서 0.38σ** 떨어져 있을 뿐이다. 즉 **설계값과 구별되지 않는다.**

| 측정 | 점 수 | Σ(x−x̄)² | 잔차 rms | 기울기 SE |
|---|---|---|---|---|
| 09-21 통합 | 5 | 25,000 | 9.86 ps | ±3492 ppm |
| **09-22** | **13** | **72,800** | 10.29 ps | **±2137 ppm** |

점을 2.6배로 늘려 SE 를 1.6배 좁혔지만, **여태 논쟁한 값들(+228 / +480 / +789 / +812)이
전부 1σ 안에 들어간다.** 그 숫자들은 차이가 아니라 잡음이었다.

### 5-3. 잔차의 정체 — 통계 잡음이 아니다

한 점은 200발의 평균이다. 산포(26~66 ps)에서 평균의 표준오차를 잡으면 1 ps 수준인데,
실제 잔차는 **10.29 ps rms**, 구간별 편차는 **15.74 ps rms** 다 (위상 120→140 에서 +27.48,
140→160 에서 −36.27 ps). 열 배 이상 크다.

즉 잔차는 **재보면 줄어드는 종류가 아니다.** 후보는 두 가지이고 아직 갈리지 않았다 :

1. **MMCM 위상 스텝의 불균일** — 한 스텝이 정확히 17.857 ps 가 아니라 자리마다 다르다
2. **TDC 자신의 INL 잔차** — 교정 후 3.6 ps 수준이므로 10 ps 를 다 설명하지는 못한다

1번이 더 크다면 "MMCM 을 참 시간축으로 쓴다" 는 Mode 0 의 전제 자체에 한계가 있다는 뜻이다.
**가설이며 확인된 바 없다.**

### 5-4. 그래서 무엇이 확인됐나

- **coarse 오류 0 / 2587** — 5 ns 경계 처리(dual-phase + DANGER)가 2587 구간에서 한 번도
  안 틀렸다. 어제 995 구간에서 0 이었던 것의 2.6배 표본이다. **이것이 이번 스윕의 성과다.**
- 이웃 간격 sd 21.97 ps (어제 23.79) — 히트 생성 경로의 지터 수준이 그대로다.
- 기울기는 이 방법으로는 못 정한다. 정하려면 스텝별 편차를 모델링하거나
  한 주기를 촘촘히(수십~수백 점) 훑어야 한다.
