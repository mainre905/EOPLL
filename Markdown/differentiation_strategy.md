## 1. 핵심 관찰: 기존 방식들의 공통 약점

**Hauser, Schnuck, Zhang(ILC), Yao — 전부 "하나의 고정된 chirp 설정에 대한 보정"을 학습한다.**

- 학습 결과물이 보정 파형/테이블 C[j] — 이것은 특정 B, T_mod, 파형 모양에 종속된다.
- B나 T_mod를 바꾸면 (거리 분해능 전환, 간섭 회피, 다중모드 측距 등 실용 FMCW에 필수) 처음부터 재학습해야 한다.
- 차량용 FMCW의 chirp agility 요구와 정면 충돌하는 구조적 한계인데, 어떤 선행 연구도 이를 다루지 않았다.

**우리 시스템만의 이점**: ps급 TDC가 매 에지에서 ν_nl(t_n) = −γ·e(n)을 주고, 그 순간 인가한 V(t_n)도 알고 있다. 즉 **(V, dν/dV) 쌍을 chirp마다 수천 개씩 공짜로 수집**한다. 이 데이터로 chirp 설정과 무관한 레이저 고유 특성을 학습할 수 있다.

## 2. 권장 차별화 패키지

### 2.1 [주 기여] Chirp-agile 모델 기반 학습 — "파형이 아니라 레이저를 학습한다"

기존: `C_{k+1}[j] = C_k[j] + K·e_k[j]` — 보정값이 학습 대상 (chirp 설정 종속)
제안: **역튜닝곡선 자체가 학습 대상 (chirp 설정 독립)**

```
학습 : K̂_L(V) = dν/dV  전압 구간별 테이블 (γ_측정[j] = 1/(τ_d·Δt_j) 과 dV/dt[j] 에서 추정, RLS/구간평균)
       + 1차 열지연 모델 (선택)
합성 : 새 chirp 요구 (B', T'_mod, 파형모양) → V(t) = 역모델로 즉시 predistortion 합성
잔차 : 기존 RC가 모델 오차만 수렴 (1~2 chirp)
```

- **KPI (논문의 핵심 그림)**: 운용 중 T_mod 5→20 kHz 또는 B 2.5→5 GHz 전환 → e_rms가 바닥까지 복귀하는 chirp 수. 기존 방식(전체 재학습, 수십~수백 chirp)과 직접 비교 가능. **이 실험을 한 EO-PLL 논문이 없다.**
- 구현: PL은 (V, γ) 쌍 수집 + RC, PS(ARM)는 RLS 식별 + 파형 합성 → **Zynq PS/PL 협조설계** 서사가 자연스럽게 나옴 (Red Pitaya 대비 차별화).
- 제목 후보: *"Chirp-Agile EO-PLL with In-Loop Tuning-Curve Identification on a Single SoC"*

### 2.2 [부 기여 1] Newton-ILC: 모델 기반 가변 학습이득

- 기존 고정 K_RC의 한계: 레이저 튜닝이득 K_L(V)은 전류 범위에 걸쳐 수 배 변함 → 고정 이득은 최대 이득 지점 기준으로 낮춰야 해서 저이득 구간 수렴이 느림.
- 제안: `C_{k+1}[j] = C_k[j] + e_k[j] / K̂_L(V[j])` (Newton형) → **파형 전 구간 균일 수렴률**, 모델 오차 한계 내 단조수렴 증명 가능.
- 2.1의 모델을 루프에 직접 연결하는 고리 역할. (이론은 적응 ILC 문헌 존재 → "EO-PLL 응용 + 실시간 구현" 신규성으로 서술)

### 2.3 [부 기여 2] 타임스탬프 도메인 칼만 실시간 경로 + innovation gating

- 상태 x = [위상오차, 주파수오차], 측정 = e(n), 측정잡음 R = TDC 캘리브레이션에서 실측한 분산 (우리는 R을 정확히 앎 — 히스토그램 데이터가 곧 잡음 모델).
- 실시간 출력 u = −L·x̂ 로 chirp 내 비반복 외란(음향진동, 전류잡음) 억제 → **RC(반복오차) + KF(비반복오차)의 2자유도 분리**가 서사.
- **Innovation gating이 cycle-slip 판정을 통계적 검정으로 대체** — 휴리스틱 임계값(|Δt−T_b|>T_b/2)보다 우아하고, 에지 누락 시 예측으로 관성 유지.
- KPI: Schnuck의 외란주입 실험(Fig.10) 재현 → 억제 대역폭 150 kHz 초과 여부 직접 비교.

### 2.4 [enabler, 신규성 주장 없음] 무중단 in-loop TDC 자가 캘리브레이션

- beat 에지는 시스템 클럭과 비동기 → 운용 중 code-density 히스토그램이 공짜로 쌓임 → ping-pong LUT 갱신.
- TDC 문헌에 온라인 캘리브레이션이 이미 있으므로 기여로 내세우지 말고 **인용 후 "EO-PLL 루프 내 최초 적용, 장시간 온도 안정성 확보"**로 서술. KPI: 수 시간 운용 중 e_rms 드리프트 유/무 비교.

### (선택) 꼭짓점 궤적 학습 — ROI/duty 확장
학습된 모델로 부드러운 꼭짓점 궤적(raised-cosine 등)을 합성해 마스크 구간 축소. 지면 남으면 부록급.

## 4. 실험 계획에 추가되는 것

1. **chirp 전환 실험** (핵심): T_mod/B 스텝 변경 → 수렴 chirp 수 측정. 비교군 = 모델 없이 RC만 (자체 ablation).
2. **외란 주입 실험**: Schnuck 방식 재현, KF 유/무 비교 → 억제 대역폭.
3. **장시간 드리프트 실험**: 자가 캘리브레이션 on/off, 온도 변화 하 e_rms 추이.
4. 기본 성능 (잔류 ν_nl,rms, 1−r², FWHM)은 기존 계획 유지 — 선행 연구와의 공통 비교축.
