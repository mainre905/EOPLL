### 1-1. 위상 스윕 기울기는 "측정 불가" 이고, 그것은 문제가 아니다

13점 적합 : 기울기 오차 **+812 ppm**, 잔차 rms 10.29 ps, **표준오차 ±2137 ppm (1σ)**.
0 에서 **0.38σ** 떨어져 있을 뿐이다. 여태 논쟁한 +228 / +480 / +789 / +812 ppm 이
전부 1σ 안에 들어간다 — 차이가 아니라 잡음이었다.

**그리고 이 값은 원리상 0 이어야 한다.**

- MMCM 위상 스텝 = VCO 주기의 **1/56** = 17.857 ps
- 샘플링 클럭 주기 = VCO 주기의 **5배** = 5000 ps
- 둘 다 같은 VCO 에서 나오므로 비율 5000/17.857 = **280 = 5×56**, 정수로 고정이다.
  VCO 가 1000 MHz 를 벗어나도 두 값이 같이 움직여 비율은 안 변한다.

따라서 측정된 ppm 은 (a) 스텝별 불균일이거나 (b) 측정 잡음이다. **척도 오차일 수 없다.**
그리고 어느 쪽이든 EOPLL 과 무관하다 — 위상 스윕은 TDC 를 **검증하는 자**이지 측정 경로가 아니다.
실제 타임스탬프는 `coarse × 5000 − 교정표[칸]` 이고 5000 ps 는 200 MHz 클럭에서 온다.

실제 측정의 척도 정확도를 정하는 것은 **ZedBoard 의 33.333 MHz 발진기**다. 아직 안 쟀다.

## 3. ★ EOPLL 루프 — 처프 안의 간섭 크로싱이 모자라는 문제

사용자 질문 : *처프 하나 안의 간섭 파형 수가 적어 처프 삼각파를 고칠 수 있는 간격이 벌어지고,
그래서 주파수 락이 안 된다. 여러 처프의 간섭 파형을 모아 촘촘하게 만들 방법은?*

### 3-1. 얼마나 모자라는가 (측정값)

`Data/waveform2.zip` → `waveform2.csv` (100 MS/s, 2 ms, CH1 = 간섭, CH2 = 처프 인가).
아래는 전부 그 CSV 에서 **계산한(derived)** 값이다.

| 항목 | 값 | 어떻게 구했나 |
|---|---|---|
| 처프 | 1.000 kHz 삼각파, pp 178 mV | 20 kHz 저역통과 뒤 한 주기 프로파일 |
| 비트 주파수 | 평균 **68.6 kHz** (램프 중앙 73~78, 꼭짓점 부근 57~62) | 500 kHz 저역통과 + 0.15σ 히스테리시스 크로싱, 인접 간격의 역수 |
| 램프 길이 | 0.5 ms | 삼각파 한 변 |
| **한 램프당 상승 크로싱** | **약 33개** (양 에지면 66) | 2 ms 에서 132개 검출 |
| DAC 파형 점 수 | 1000점/처프 → 한 램프 **500점** | `dac_chirp_engine` (확인 필요) |

**500점을 고쳐야 하는데 측정점이 33~66개다. 8~15배 부족하다.** 이것이 "제어 간격이 벌어진다" 의 정체다.

### 3-2. 타이밍 정밀도는 문제가 아니다

TDC 재현성 1.4 ps, 비트 주기 13.2 µs (76 kHz). 크로싱 하나의 위상 분해능은

```
2π × 1.4 ps / 13.2 µs ≈ 6.7 × 10⁻⁷ rad
```

**부족한 것은 샘플의 질이 아니라 개수다.** 그러므로 해법은 "개수를 늘리거나, 적은 개수로
충분하게 만들거나" 둘뿐이다.

### 3-3. 네 가지 방법

#### A. 간섭계 지연 τ 를 늘린다 — 가장 직접적

`f_beat = γ·τ` 이므로 **광섬유 지연에 비례해 크로싱이 는다.** 10배면 330개/램프로 DAC 점수에 근접한다.

한계 :
- **레이저 coherence.** τ 가 coherence time 을 넘으면 간섭 대비가 무너진다.
  선폭 Δν 에 대해 대략 τ ≪ 1/(πΔν). `Markdown/` 의 선폭 측정 문서로 상한을 먼저 계산할 것
- 비트 주파수가 같이 오른다 (76 kHz → 760 kHz). TDC 의 **dead time 2클럭(10 ns)** 과
  처리율을 확인해야 한다
- τ 에 비례해 위상잡음도 는다

#### B. 양쪽 에지를 쓴다 — 공짜로 2배

한 크로싱 = π 위상이므로 상승만 쓰면 정보의 절반을 버리는 것이다. 비교기 출력을 양 에지로
타임스탬프하면 된다. 문턱을 하나 더 두면(비교기 2개) 4배까지 가지만, 0 이 아닌 문턱은
진폭 변동에 민감해져 보정이 필요하다.

#### C. ★ 여러 처프에 걸쳐 버니어 누적 — 질문에 대한 직접적 답

**그냥 모으면 안 된다.** 처프가 매번 같으면 크로싱도 **매번 같은 자리**에 떨어진다.
100번 모아도 33개 위치에 100겹 쌓일 뿐이다. **일부러 위치를 밀어야 한다.**

**미는 방법 : 처프마다 아주 작은 DC 오프셋을 더한다.**

간섭계 출력 위상은 대략 `φ(t) ≈ 2π·τ·f(t)` 다. 처프 전체에 일정한 주파수 오프셋 Δf 를 주면
위상이 `2π·τ·Δf` 만큼 통째로 밀린다 — **기울기 γ 는 그대로이므로 비트 주파수는 안 변하고
크로싱 위치만 이동한다.**

M 번에 걸쳐 한 fringe 를 균등하게 훑으려면 :

```
Δf_step = 1 / (M · τ)
ΔV_step = Δf_step / (레이저 튜닝계수 [GHz/V])
```

예 : τ = 100 ns (광섬유 약 20 m), M = 16 → Δf = 625 kHz.
레이저가 1 GHz/V 라면 **ΔV = 0.6 mV**. 처프 진폭이 178 mVpp 이고 DAC 가 16비트이니 여유롭다.

그러면 16 처프 = **16 ms** 에 33 × 16 = **528개** 위치가 모여 DAC 500점과 맞는다.
갱신율 **62.5 Hz** — 레이저 열드리프트를 쫓기에 충분하다.

> **이것은 TDC 가 이미 쓰는 방법의 광학판이다.** MMCM 위상을 한 스텝씩 밀며 탭을 훑는
> 키 4 의 방식과 원리가 같다.

> 자유 발진 레이저는 절대 주파수가 저절로 떠돌아서 **가만 둬도** 크로싱이 처프마다 다른 자리에
> 떨어진다. 그래서 "그냥 누적" 도 어느 정도는 통한다. 하지만 커버리지가 무작위라 빈 구간이
> 생기고 몇 처프가 필요한지 보장이 없다. **일부러 미는 쪽이 결정론적이라 낫다.**

#### D. 1000점을 다 측정할 필요가 없다 — 저차 파라미터화

처프 비선형성이 정말 1000개의 독립 자유도를 갖는가? 레이저 주파수 비선형성은 주로
(a) 주입전류에 대한 즉각 응답, (b) 열 시정수(µs~ms) 에서 온다. **둘 다 매끄러운 저차 함수**다.
실제로 측정된 비트 프로파일도 램프 안에서 57~78 kHz 로 완만하게 변할 뿐 들쭉날쭉하지 않다.

그렇다면 보정을 1000점 룩업이 아니라 **다항식/스플라인 10~20개 계수**로 두면, 33개 측정점으로도
**과결정**이 되어 최소제곱으로 안정하게 풀린다. DAC 에는 여전히 1000점을 쓰되 그 1000점을
20개 계수에서 생성한다.

### 3-4. 권장 구조

```
처프 재생 (DAC 1000점, 처프 안에서는 개루프)
   ↓
비교기 → TDC 타임스탬프 (크로싱마다 π 위상)
   ↓
처프 내 위치로 binning   ← M개 처프 누적
   ↓                       (처프마다 ΔV 오프셋으로 위치를 2π/M 씩 이동)
위상오차 φ_err(위치) 를 저차 기저로 최소제곱
   ↓
ILC 갱신 :  u_{k+1} = u_k + g · (보정량)     (학습이득 g = 0.2~0.5)
   ↓
비활성 BRAM 에 기록 → CTRL.SWAP_REQ → 처프 경계에서 교체
```

**처프 안에서는 피드백을 걸지 않는다.** 샘플이 33개뿐인데 루프를 빠르게 돌리면 에일리어싱으로
발산한다. 처프 내부는 개루프, **처프 간(iteration 간)에만 학습**한다.
`dac_chirp_engine` 의 핑퐁 BRAM 이 바로 이 구조를 위한 것이다
(`tcl/bd_eopll_sys.tcl` 주석 : "나중에 TDC 보정 파형을 끊김 없이 넣는 경로가 이것이다").

여기에 **평균 비트 주파수를 목표에 맞추는 느린 스칼라 PI** 를 하나 더 두면, 전체 기울기 γ 는
그쪽이 잡고 ILC 는 모양만 다듬는다. 두 루프의 대역이 분리되어 서로 싸우지 않는다.

### 3-5. 적용 순서

1. **τ 증가** — 하드웨어 하나로 선형 이득. 선폭에서 상한부터 계산
2. **양 에지** — 공짜 2배
3. **위치 binning + ILC** — 구조를 이걸로 짠다 (처음엔 자연 드리프트에 의존해도 된다)
4. **ΔV 버니어** — 커버리지를 결정론적으로 만든다
5. **저차 파라미터화** — 33점으로도 풀리게 만든다

1·2 만 해도 33 → 130개, 여기에 M=4 누적이면 520개로 DAC 점수와 맞는다.

### 3-6. ★ 설계를 확정하려면 필요한 숫자 셋

| 필요한 값 | 무엇을 정하나 | 현재 |
|---|---|---|
| **간섭계 지연 τ** (또는 광섬유 길이) | 크로싱 개수, ΔV 스텝 크기 | **모름** |
| **레이저 튜닝 계수** [GHz/V 또는 GHz/mA] | ΔV 스텝을 전압으로 환산 | **모름** |
| **처프 한 주기의 DAC 점 수** | 보정 격자의 크기 | 1000 으로 가정 |

이 셋이 있으면 M(누적 처프 수), ΔV, 갱신율을 숫자로 뽑고 루프 RTL 구조를 확정할 수 있다.
